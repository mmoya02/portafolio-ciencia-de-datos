## Proyectos destacados

### Modelo predictivo en Apache Spark MLlib

Proyecto de clasificación binaria desarrollado con PySpark y Spark MLlib para identificar transacciones potencialmente riesgosas.

**Tecnologías utilizadas:**
- Python
- PySpark
- Apache Spark
- Spark MLlib
- Random Forest

**Resultados principales:**
- Accuracy: 93,10 %
- AUC: 0,9192

Este proyecto permitió aplicar preparación de datos, creación de variables, entrenamiento de un modelo supervisado y evaluación mediante métricas.
